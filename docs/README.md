# Documentacion tecnica

Esta carpeta contiene documentos de apoyo para entender y probar el proyecto.

La memoria oficial del TFG es el documento principal. Estos Markdown son documentacion tecnica complementaria del repositorio y resumen la instalacion, endpoints, pruebas y decisiones basicas del proyecto.

Archivos principales:

- `MANUAL_INSTALACION_Y_ARRANQUE.md`: pasos para preparar MySQL, backend y frontend.
- `ENDPOINTS.md`: resumen de las rutas REST del backend.
- `SEGURIDAD_Y_RESPONSIVE.md`: decisiones de seguridad basica y revision responsive.
- `PRUEBAS_ENTREGA.md`: recorrido recomendado para comprobar la aplicacion antes de entregarla.

Los documentos de presentacion o plantillas externas no forman parte del codigo fuente y no se suben al repositorio.
