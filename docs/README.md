# Documentación técnica de ConectaDJ

Esta carpeta contiene documentos de apoyo para entender y probar el proyecto.

La memoria oficial del TFG es el documento principal. Estos Markdown son documentación técnica complementaria del repositorio y resumen la instalación, endpoints, pruebas y decisiones básicas del proyecto.

Archivos principales:

- `MANUAL_INSTALACION_Y_ARRANQUE.md`: pasos para preparar MySQL, backend y frontend.
- `ENDPOINTS.md`: resumen de las rutas REST del backend.
- `SEGURIDAD_Y_RESPONSIVE.md`: decisiones de seguridad básica y revisión responsive.
- `PRUEBAS_ENTREGA.md`: recorrido recomendado para comprobar la aplicación antes de entregarla.
- `GUIA_ARRANQUE_Y_DEMO.md`: guía completa para arrancar el proyecto y usar los usuarios de demo.
- `RUTA_DEMO_PRESENTACION_TFG.md`: ruta recomendada para enseñar la demo durante la defensa sin pasarse de tiempo.
- `FOTOS_DEMO/`: imágenes preparadas para perfiles, organizadores, ofertas y candidaturas durante la exposición.
- `ACCESO_RAPIDO_FOTOS_DEMO.md`: explicación para abrir la carpeta de fotos y la aplicación antes de enseñar la subida de imágenes.
- `ABRIR_DEMO_CON_FOTOS.cmd`: acceso rápido local para abrir `localhost:5173`, abrir `FOTOS_DEMO` y copiar la ruta al portapapeles.

Los documentos de presentación o plantillas externas no forman parte del código fuente y no se suben al repositorio.
