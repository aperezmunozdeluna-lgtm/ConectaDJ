# Fotos preparadas para la demo

Esta carpeta contiene imágenes de apoyo para usar durante la exposición del TFG sin perder tiempo buscando archivos.

Las imágenes están pensadas para subirlas desde la aplicación cuando se edite un perfil o se cree una oferta nueva durante la demo.

## Estructura

```text
FOTOS_DEMO/
|-- fotos_djs/
|   |-- perfiles/
|-- fotos_candidaturas/
|-- fotos_organizadores/
|   |-- perfiles/
|   |-- ofertas/
|-- fotos_reserva_presentacion/
|   |-- djs/
|   |-- organizadores/
|   |-- ofertas/
|   |-- genericas/
```

## Qué carpeta usar

| Caso | Carpeta recomendada |
|---|---|
| Foto de perfil de un DJ | `fotos_djs/perfiles/` |
| Foto para una candidatura de DJ | `fotos_candidaturas/` |
| Foto o logo de organizador | `fotos_organizadores/perfiles/` |
| Imagen de una oferta | `fotos_organizadores/ofertas/` |
| Imagen improvisada durante la defensa | `fotos_reserva_presentacion/` |
